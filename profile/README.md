## 🚀 我们在做什么 · What We Build

我们是一支来自**大湾区**的 Agent 建造团队，把重复的运营与内容工作交给 AI Agent。
We're an agent-builder team from the **Greater Bay Area**, turning repetitive ops & content work into autonomous agents.

- 🌐 **GEO 内容自动化** — 从选题、生产、审核到发布的一体化内容流水线
  End-to-end GEO content pipeline: ideation → production → review → publishing

- 🔌 **Agent 基建 · Infra** — MCP 服务、LLM 网关、消息平台桥接
